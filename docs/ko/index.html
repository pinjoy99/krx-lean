내 컴퓨터에서 하는
한국 주식 백테스트

krx-lean은 KOSPI 주식과 ETF에 대한 투자 아이디어를 검증하는 도구입니다. Python이나 C#으로 전략을 작성해 여러 해의 과거 데이터로 실행하면, 한국의 수수료와 세금까지 반영한 성과를 확인할 수 있습니다.

무료 오픈소스 내 컴퓨터에서 실행 계정 불필요 Python 또는 C# Linux · Windows(WSL2)
시작하기 GitHub에서 보기

무엇을 할 수 있나요

백테스트는 과거를 다시 재생하는 것입니다. 전략이 매일 무엇을 사고팔지 결정하고, 그 결과 얼마를 벌었거나 잃었을지를 보여 줍니다. krx-lean은 한국 시장에서 이를 하는 데 필요한 것을 모두 제공합니다.

한국 시장 데이터

2010년 이후 모든 KOSPI 종목과 ETF의 일별 시세(상장폐지 종목 포함)를 본인의 무료 인증키로 거래소 공식 API에서 내려받습니다.

한국 시장 규칙

수수료, 시기별 증권거래세, KRX 호가가격단위, 액면분할과 배당 조정, 그리고 비교 기준이 되는 KOSPI 200.

전문가용 엔진

많은 퀀트 투자자가 쓰는 오픈소스 엔진 LEAN을 내 컴퓨터에서 소스로 빌드해 사용합니다.

쉬운 도구 하나

klean 명령 하나로 설치, 백테스트, 결과 비교, 파라미터 탐색, 리포트, 리서치 노트북, 브라우저 화면까지 처리합니다.

투자 조언이 아닙니다. 과거 성과가 미래 수익을 보장하지 않으며, 백테스트는 가정한 만큼만 정확합니다. 슬리피지는 기본적으로 꺼져 있고(켤 수 있습니다, 아래 참조), 가격제한폭은 아직 반영하지 않으며, krx-lean은 실제 주문을 내지 않습니다.

시작하기

30~45분쯤 걸리며 대부분은 내려받기를 기다리는 시간입니다. 명령을 터미널에 복사해 붙여넣으면 됩니다. 회색 상자마다 Copy 버튼이 있습니다. 이 단계에는 API 인증키가 필요 없습니다. 먼저 가상(합성) 데모 데이터로 모든 기능을 써 봅니다.

1

Linux 터미널 열기 5~10분

krx-lean은 Linux에서 실행됩니다. Windows 10/11은 WSL2로 Windows 안에서 Linux를 실행할 수 있습니다. PowerShell을 관리자 권한으로 열고(시작 버튼 우클릭 → 터미널(관리자)) 다음을 실행하세요.

wsl --install -d Ubuntu-24.04

안내에 따라 다시 시작한 뒤 시작 메뉴에서 Ubuntu를 열어 사용자 이름과 암호를 정합니다. 이 창이 아래 모든 단계에서 쓰는 터미널입니다. 파일은 Ubuntu의 홈 폴더(~)에 두세요. /mnt/c 아래는 훨씬 느립니다.

터미널을 엽니다. Ubuntu 24.04와 22.04에서 테스트했습니다. 다른 배포판도 같은 순서로 동작할 것입니다(2단계의 패키지를 해당 배포판 방식으로 설치하세요).

Apple Silicon macOS는 실험적입니다. 자동 검사는 통과하지만 사람이 직접 따라 해 보지는 않았습니다. 2단계 대신 macOS 설치 순서(영문)를 따른 뒤 3단계부터 이어 가세요. 검증된 환경이 필요하면 Linux나 WSL2가 있는 Windows PC를 이용하세요.

2

도구 설치 10~25분

시스템 패키지, .NET 10 SDK(LEAN은 C#으로 작성됨), 그리고 LEAN용 Python 3.11을 제공하는 uv를 설치합니다. 첫 명령에서 암호를 묻습니다.

sudo apt update
sudo apt install -y git curl unzip python3 python3-venv libicu-dev
curl -sSL https://dot.net/v1/dotnet-install.sh | bash -s -- --channel 10.0
curl -LsSf https://astral.sh/uv/install.sh | sh
echo 'export DOTNET_ROOT="$HOME/.dotnet"' >> ~/.bashrc
echo 'export PATH="$HOME/.dotnet:$HOME/.krx-lean/venv/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc

이어서 krx-lean, LEAN, LEAN용 Python 3.11을 설치합니다.

git clone https://github.com/pinjoy99/krx-lean.git ~/krx-lean
python3 -m venv ~/.krx-lean/venv
~/.krx-lean/venv/bin/pip install -e ~/krx-lean
klean install-lean --dir ~/Lean              # LEAN 내려받기와 빌드 (2~10분)
klean install-python --dir ~/.klean/py311    # LEAN용 Python 3.11 + pandas

확인: klean --version이 버전 번호를 출력합니다. LEAN 빌드 중 나오는 경고(warning)는 정상입니다.

3

데모 워크스페이스 만들기 1분

워크스페이스는 전략과 그 결과를 담는 폴더입니다. 여기에는 가상 데모 데이터를 넣습니다. 실제 주식시장처럼 움직이도록 만들어 낸 가짜 종목과 지수라서, 인증키가 나오기 전에도 모든 기능을 익힐 수 있습니다.

klean init ~/krx-demo --lean ~/Lean --python-venv ~/.klean/py311
cd ~/krx-demo
klean data install --demo
klean doctor                   # 모든 줄이 OK여야 합니다
데모 데이터는 실제 데이터가 아닙니다. 종목(코드 D00010…)은 존재하지 않는 회사이며, klean은 모든 결과에 "SYNTHETIC DEMO DATA"라고 표시합니다. 도구를 배우기 위한 것이지 전략을 평가하기 위한 것이 아닙니다.
4

첫 백테스트 실행 2분

준비된 예제(시가총액 상위 20종목을 같은 비중으로 사서 매달 리밸런싱)로 프로젝트를 만들어 2011~2026년 구간으로 실행합니다.

klean project-create Top20 --template top-market-cap
klean backtest Top20

1~2분 뒤 연평균 수익률(CAGR), 최대 낙폭(drawdown), 최종 자산 같은 통계가 나옵니다. 이어서 자세히 살펴봅니다.

klean report Top20      # 상세 HTML 리포트
klean gui               # 브라우저에서 결과 보기

WSL에서는 sudo apt install -y wslu를 설치하면 klean gui가 Windows 브라우저를 엽니다. 또는 출력된 주소를 직접 여세요. 종료는 Ctrl+C입니다.

5

노트북으로 데이터 살펴보기 처음에는 5분

노트북(Jupyter)에서는 전략을 쓰기 전에 시세를 보고, 지표를 계산하고, 차트를 그려 가며 한 단계씩 살펴볼 수 있습니다. 처음 실행할 때 klean이 JupyterLab을 설치합니다(몇 분).

klean research Top20

브라우저에 LEAN이 이미 로드된 노트북이 열립니다. Run → Run All Cells를 선택하면 한 종목의 시세를 불러와 60일 이동평균을 그리고 KOSPI 200과 비교합니다. 코드를 바꿔 다시 실행해 보세요. 종료는 터미널에서 Ctrl+C입니다.

결과 읽기

숫자의 의미입니다. (그림은 데모 데이터로 만든 것이라 수치는 가상의 값입니다.)

항목의미
Compounding Annual Return (CAGR, 연평균 수익률)해마다 평균적으로 불어난 비율. 8%면 약 9년에 원금이 두 배가 됩니다.
Drawdown (최대 낙폭)고점에서 가장 크게 떨어진 폭. 50%면 최악의 순간에 절반을 잃었다는 뜻입니다. 그 기간을 버틸 수 있을지 생각해 보세요.
Sharpe Ratio (샤프 비율)위험(변동) 한 단위당 수익. 높을수록 좋으며, 장기간 1을 넘기는 드뭅니다.
Benchmark (KOSPI 200)시장을 그냥 보유했을 때의 성과. 애써 만든 전략이라면 수수료를 내고도 이보다 나아야 합니다.
Total Fees (총 비용)냈을 수수료와 증권거래세. 자주 매매하면 비용이 큽니다.
Slippage (슬리피지)백테스트가 가정한 가격과 실제 시장에서 체결되는 가격의 차이. 기본은 꺼짐입니다. klean backtest Top20 --parameter slippage_ticks 1로 켜면 더 보수적인 결과를 볼 수 있습니다.
Alpha / Beta베타: 전략이 시장과 함께 움직이는 정도(1이면 같음). 알파: 시장으로 설명되지 않는 수익.

실제 데이터 사용하기

익숙해졌다면 실제 KOSPI 데이터를 받으세요. 무료지만 본인 인증키가 필요하고 승인에 하루쯤 걸릴 수 있으니 미리 신청해 두세요.

1

인증키 받기

KRX Open API(필수, 시세): openapi.krx.co.kr에 가입해 인증키를 신청하고, 유가증권 일별매매정보, ETF 일별매매정보, KOSPI 시리즈 일별시세정보 서비스의 이용을 신청합니다. 공공데이터포털(권장, 배당): data.go.kr에서 금융위원회_주식배당정보 활용을 신청합니다. 단계별 안내(영문).

2

안전하게 보관하기

본인만 읽을 수 있는 파일에 넣습니다(코드에는 절대 넣지 마세요).

mkdir -p ~/.config && touch ~/.config/krx-lean.env && chmod 600 ~/.config/krx-lean.env
nano ~/.config/krx-lean.env
KRX_API_KEY=your-krx-key
DATA_GO_KR_KEY=your-data-go-kr-key
3

데이터 내려받기와 빌드 처음 한 번, 1.5~2시간

set -a; . ~/.config/krx-lean.env; set +a
krx-lean --root ~/krx-data all

2010년 이후 모든 거래일을 내려받습니다. 중간에 멈추면 같은 명령을 다시 실행하세요. 멈춘 곳부터 이어집니다. 이후 업데이트는 1분 정도면 됩니다.

4

실제 데이터용 워크스페이스

klean init ~/krx-workspace --lean ~/Lean --python-venv ~/.klean/py311
cd ~/krx-workspace
klean data install --root ~/krx-data

데모와 실제 데이터의 워크스페이스는 따로 두세요(klean이 섞이지 않게 막습니다). 나중에 새 거래일을 받으려면 워크스페이스에서 klean update를 실행합니다.

나만의 전략 만들기

전략은 작은 Python 프로그램입니다. 빈 프로젝트를 만들고 main.py를 아래 내용으로 바꾸세요. 두 종목을 절반씩 보유하며 매달 리밸런싱하는 전략입니다(아이디어는 먼저 프로젝트 노트북에서 시험해 보세요: klean research MyFirst).

klean project-create MyFirst --template empty
nano MyFirst/main.py
from AlgorithmImports import *
from krx_models import KrxBoards, krx_benchmark, krx_initialize


class MyFirstStrategy(QCAlgorithm):
    """Hold two stocks, half each, and rebalance at the start of every month."""

    def initialize(self):
        self.set_start_date(2015, 1, 1)
        self.set_end_date(2025, 12, 31)
        self.set_cash(100_000_000)                       # 1억 원
        self.set_time_zone("Asia/Seoul")
        self.set_account_currency("KRW")
        boards = KrxBoards.load()
        self.set_security_initializer(lambda s: krx_initialize(s, boards))   # KRX 수수료, 세금, 호가단위
        self.set_benchmark(krx_benchmark("kospi200"))    # KOSPI 200과 비교

        codes = ["D00010", "D00050"]                     # 데모 종목. 실제 데이터 예: ["005930", "000660"]
        self.stocks = [self.add_equity(c, Resolution.DAILY, Market.KRX).symbol for c in codes]
        self.last_month = 0

    def on_data(self, data: Slice):
        if self.time.month == self.last_month:           # 한 달에 한 번
            return
        if not all(data.contains_key(s) for s in self.stocks):
            return
        self.last_month = self.time.month
        for s in self.stocks:
            self.set_holdings(s, 0.49)                   # 약 절반씩, 수수료용 현금 조금
klean backtest MyFirst

set_time_zone부터 set_benchmark까지의 줄은 모든 전략에 그대로 두세요. 한국 시장 규칙을 적용하는 부분입니다. 실제 데이터에서는 005930(삼성전자), 000660(SK하이닉스) 같은 실제 종목코드를 쓰세요. 더 알아보려면 전략 작성 안내(영문)와 LEAN의 알고리즘 문서를 보세요.

자주 묻는 질문

비용이 드나요?

아니요. krx-lean, LEAN, 데이터 API 모두 무료입니다. QuantConnect 계정이나 구독도 필요 없습니다.

실제 돈으로 매매할 수 있나요?

아직은 아닙니다. 과거 데이터로 전략을 검증하기만 합니다. 증권사와는 전혀 연결되지 않습니다.

어떤 시장과 데이터를 다루나요?

KOSPI 주식과 ETF의 2010년 이후 일별 시세입니다. KOSDAQ, KONEX, 장중(분 단위) 데이터는 아직 다루지 않습니다.

Python과 C# 중 무엇을 쓰나요?

어느 쪽이든 결과는 같습니다. Python이 시작하기 쉽고, C#은 몇 배 빨라서 긴 기간의 테스트나 최적화에 유리합니다.

백테스트가 "backtest FAILED"라고 나옵니다.

klean이 바로 아래에 전략에서 난 오류를 줄 번호와 함께 보여 줍니다. 그 줄을 고쳐 다시 실행하세요. klean logs PROJECT --console은 LEAN의 전체 출력을 보여 주며, 문제 해결 안내(영문)에 자주 나오는 메시지가 정리되어 있습니다.

데이터는 어디에 저장되나요?

내 컴퓨터에만 저장됩니다. 내려받은 데이터는 ~/krx-data에, 전략과 결과는 워크스페이스에 있습니다. 내려받은 데이터는 각 제공처의 이용약관을 따르므로 공유하거나 공개하지 마세요.

QuantConnect나 한국거래소와 관련이 있나요?

아니요. krx-lean은 LEAN(Apache-2.0)을 수정 없이 사용하는 독립적인 오픈소스 프로젝트입니다.
